# Chess Connect 4
체스의 기물 이동 방식과 오목의 승리 조건을 결합한 턴제 전략 보드 게임  

## 프로젝트 개요
기존의 체스 규칙에 '사목(Connect 4)'이라는 승리 조건을 더해 새로운 게임 메커니즘을 시도한 유니티 기반 1인 개발 프로젝트. 
상용 엔진의 컴포넌트 기반 설계를 이해하고, 복잡한 보드 게임의 자원 밸런싱 구현.  
개발 환경: Unity, C#  
개발 인원: 1인 개발  
핵심 키워드: Vector3 이동 제어, 자원 관리 시스템, 쿼터니언 시점 제어  

## 주요 구현 특징
1. 3차원 벡터를 이용한 이동 제어 시스템
* 방향 간섭 차단: 룩이나 비숍처럼 특정 방향성이 강제되는 기물의 이동을 제어하기 위해, 가로·세로·대각선을 각각의 축으로 정의한 Vector3 시스템 설계.
* 연산 단순화: 2D 좌표 평면에서 발생할 수 있는 방향 판정의 모호함을 3차원 축 정의를 통해 원천 차단하여 기물 이동 연산 최적화.
2. 전략적 자원 및 생명주기 관리
* 비대칭 코스트 배분: 선공 유리성을 상쇄하기 위해 선·후공의 초기 자원을 차등 배분하여 전략적 균형 조정.
* 기물 묘지(Grave) 시스템: 파괴된 기물을 3턴간 격리하는 시스템을 도입하여, 저코스트 기물의 무분별한 물량 공세 방지 및 자원 운용의 긴장감 부여.
3. 유니티 컴포넌트 기반 UI/UX 및 시점 제어
* 사원수(Quaternion) 기반 역회전: 보드 회전 시 자식 객체(기물)에 역회전을 적용하여, 보드의 방향과 관계없이 기물의 정면 이미지가 항상 유저를 향하도록 설계.
* 직관적 인터페이스: ToggleGroup을 활용해 기물 선택 및 설치 가능 영역 하이라이팅 시스템을 구축하여 유저 피드백 강화.

## 레포지토리 구조
/Assets/Scripts: 기물 이동 로직, 자원 관리 매니저 및 UI 제어 스크립트
/Assets/Prefabs: 각 기물의 속성과 컴포넌트가 설정된 프리팹 데이터
/ProjectSettings: 입력 및 레이어 설정 등 유니티 프로젝트 환경 설정 값
